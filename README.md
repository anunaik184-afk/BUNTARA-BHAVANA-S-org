# Buntara Bhavana Hall Booking Platform 🏛️

A digital venue booking and management platform designed for **Buntara Bhavana, Kombettu, Puttur**[cite: 2, 3]. Built for **ByteRace 2026** at **Vivekananda College of Engineering & Technology, Puttur**[cite: 1].

---

## 🚨 Problem Statement
Traditional hall booking processes rely heavily on manual record-keeping, offline scheduling, and physical visits[cite: 2]. This often leads to double-booking conflicts, lack of transparency in availability, slow confirmation workflows, and poor accessibility for community members seeking to reserve event spaces[cite: 2].

---

## 💡 Solution
The **Buntara Bhavana Hall Booking Platform** provides a centralized online booking system[cite: 2]. Users can check real-time venue availability, submit booking requests, manage reservation details, and receive instant updates through a responsive web application[cite: 2, 3].

---

## 🛠️ Tech Stack

* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS[cite: 2]
* **Backend:** Node.js, TypeScript (`server.ts`), Express, Bun Runtime[cite: 2]
* **Database & Storage:** Persistent File Storage (`/data` directory), LocalStorage[cite: 2]
* **Hosting & Deployment:** Google Cloud Run / Vercel[cite: 2, 3]
* **Tools & AI:** VS Code, GitHub, ChatGPT[cite: 2]

## ⚙️ Setup & Installation

### Prerequisites
* [Node.js](https://nodejs.org/) (v18 or higher) or [Bun](https://bun.sh/)[cite: 2]
* [Git](https://git-scm.com/)[cite: 2]

### 1. Clone the Repository
```bash
git clone [https://github.com/anunaik184-afk/BUNTARA-BHAVANA-S-org.git](https://github.com/anunaik184-afk/BUNTARA-BHAVANA-S-org.git)
cd BUNTARA-BHAVANA-S-org
```[cite: 2]

### 2. Install Dependencies
```bash
bun install
```[cite: 2]

### 3. Configure Environment Variables
Create a `.env` file in the root directory using `.env.example`:
```bash
cp .env.example .env
```[cite: 2]

### 4. Run the Development Server
```bash
# Start backend server
bun run server.ts

# Start frontend development server
bun run dev
```[cite: 2]
